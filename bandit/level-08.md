# Level 7 -> 8

This level is fairly simple, we just have to use the `grep` command to find the password next to a certain keyword like so: 

<img width="402" height="21" alt="image" src="https://github.com/user-attachments/assets/3a46d519-0129-4ee7-aa0a-fef287115425" />

This works because grep prints every line that contains the keyword that you're searching for is on, and in this case the password is next to the word "millionth"

- Note that grep is case-sensitive, and that you can use the `-i` flag to make it not case-sensitive
